# Shared Massas footage

Language-neutral derivatives of the eight documented Spanish lessons. The separate
120px Spanish text band is cropped from the 1280x720 originals; the complete
1280x600 demonstration image, its timing, and its lack of audio are preserved.
Localized, synchronized instructions appear below the player on each member page.
Posters are cropped in the same way. Encoding: H.264, yuv420p, faststart.

These files are served from /massas-es-m/assets/videos/shared/ and reused by
the Czech, Danish, German, Finnish, French, Italian, Dutch, Norwegian, Polish
and Swedish member areas. Keep this shared directory when updating deployments.

For original source links, authors, licenses and selected time ranges, see
../../../VIDEO_SOURCES.md. Derivatives retain the corresponding CC BY 3.0,
CC BY 4.0 or CC BY-SA 4.0 license; credits are also shown under each lesson.
