Todo listo para empezar.

Ayuda para leer, descargar e imprimir tus libros.

¿Por dónde empiezo?

Elige un libro y pulsa «Leer libro». Las primeras páginas presentan la historia y explican las actividades. Puedes probar otro libro cuando quieras.

¿Cómo imprimo una actividad?

Pulsa «Abrir PDF para imprimir». En el cuadro de impresión de tu lector de PDF, selecciona las páginas que quieras y revisa la vista previa. Puedes resolver las actividades impresas con un lápiz.

¿Puedo usar los libros sin internet?

Sí. Descarga los PDF originales en tu dispositivo y ábrelos con un lector de PDF. El área de miembros necesita una conexión a internet.

¿Se guarda mi última página?

La última página abierta se guarda solo en este navegador y en este dispositivo. No se sincroniza entre dispositivos. Borrar los datos del navegador o usar el modo privado puede eliminarla.

¿Necesitas ayuda con el acceso?

Te ayudamos si no puedes abrir o descargar tus libros.
